This repository details how to create a CV web page on github. 
first step, open vscode, go to extensions, install Github repositories
go to remote explorer, click on the + sign, and click on open repository from github, then choose a repo to load.
go to explorer, the repo should have been loaded there 
control +shift+ p, type codeswing:new string. An index.html file will be created 
convert your pdf, word cv to html format and copy the html into the index.html file. A second windown will pop up showing what how the layout look like.
Then, go to the chat, tell chat what you want; colour, layout, arrangemnt etc ...play around until the preferred layout is generated.
go to source control, and type in resume, then click push and commit (after these step, all changes will be uploaded to github)
go to github website, click on the repository , go to settings, click on pages, change branch from none to main and click save. the website link will be generated automatically. copy and verify. To verify if the site is published, go to actions (all workflows are there), if there is a green tick, it means the site is live.
